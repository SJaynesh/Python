# File Handling

 - We can handle any text files using python for reading, or writing purpose.
 - It means, we can open, read from, and write into any text file using python.

<br><br>

 ## Modes of Opening a file:

  1. r - Read
  2. w - Write
  3. a - Append
  4. x - Create
  5. t - Text Mode
  6. B - Binary Mode

`NOTE:` By default, the mode is set to "r" or "rt".

<br><br>

## Syntax :
`open(filePath, mode)`
